# Lessons (bones): the rule and the test that keep a failure from happening twice

| Date | Born from | What went wrong | Rule | Test | Reaches |
| --- | --- | --- | --- | --- | --- |
| 2026-11-08 | DESK-0019 | Typing `desk` in PowerShell opened Display Settings: Windows ships `System32\desk.cpl`, which wins over uv's tool directory on PATH. | Before naming an executable, check the name on every target OS (`Get-Command <name> -All` on Windows, `type <name>` on macOS/Linux) and ship a collision-free alias. | A test that `Get-Command drew -All` resolves only to the uv shim; a README note per OS. | every project that installs a command |
| 2026-11-08 | DESK (bug: doubled comment) | A comment form with no feedback on submit let one click become two identical comments; the server stored both. | Every state-changing form disables its button, confirms on return, carries a one-time token, and the server refuses an identical repeat within a short window. | A test that posts the same comment twice and finds one line. | every product with a form |
| 2026-11-08 | DESK (bug: stale install) | Restarting the UI showed old code because the installed tool had not been reinstalled and nothing on screen said which version was running. | Every app shows its version and commit where the user looks; a `doctor` command compares installed and repo versions; the refresh steps are in the README. | A test that the footer carries the version; `drew doctor` exits non-zero when stale. | every installed tool |
