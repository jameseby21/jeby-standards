# Lessons (bones): the rule and the test that keep a failure from happening twice

| Date | Born from | What went wrong | Rule | Test | Reaches |
| --- | --- | --- | --- | --- | --- |
| 2026-11-08 | DESK-0019 | Typing `desk` in PowerShell opened Display Settings: Windows ships `System32\desk.cpl`, which wins over uv's tool directory on PATH. | Before naming an executable, check the name on every target OS (`Get-Command <name> -All` on Windows, `type <name>` on macOS/Linux) and ship a collision-free alias. | A test that `Get-Command drew -All` resolves only to the uv shim; a README note per OS. | every project that installs a command |
| 2026-11-08 | DESK (bug: doubled comment) | A comment form with no feedback on submit let one click become two identical comments; the server stored both. | Every state-changing form disables its button, confirms on return, carries a one-time token, and the server refuses an identical repeat within a short window. | A test that posts the same comment twice and finds one line. | every product with a form |
| 2026-11-08 | DESK (bug: stale install) | Restarting the UI showed old code because the installed tool had not been reinstalled and nothing on screen said which version was running. | Every app shows its version and commit where the user looks; a `doctor` command compares installed and repo versions; the refresh steps are in the README. | A test that the footer carries the version; `drew doctor` exits non-zero when stale. | every installed tool |
| 2026-11-08 | JEBYUS-0047 | A site built in a cloud session failed on a clean Windows checkout (mkdir on an existing folder). | A PR that says it builds must show a clean-checkout build on each supported OS, or name the OS as unverified. | The release process runs `python _src/build.py` from a fresh clone on Windows and macOS. | every project with a build step |
| 2026-11-08 | Patch (JEBYUS-0001 record) | Patch wrote 'both sites built' into a ticket from the plan before reading the exit code; the build had failed. | Evidence is written after the command returns, from its exit code and output, never from the intention to run it. | A Report line that names a command carries its exit status and the counted output. | every session, every Report |
| 2026-11-08 | DESK-0082 | A fix passed its tests in the repo while the user kept testing the old running instance; the ticket read as if the fix was proven. | A fix is verified on the instance the user runs (restart it, show the version), and the ticket says which instance was tested. | `drew doctor` reports installed commit; the Report names the commit and port the check ran on. | every running tool |
| 2026-11-08 | DESK-0095 | Reinstalling a package under a running server mixed old modules with new templates and produced three different 500s for the user. | Never reinstall under a running instance; the upgrade command refuses while one runs; the app compares its build stamp with the files on disk and shows a restart notice. | Test: stamp mismatch renders the restart bar; `drew upgrade` refuses with the PID. | every long-running tool |
