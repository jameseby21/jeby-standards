# admin (paperwork, accounts, filings, payments, calendar)

- [ ] The exact action, the entity it is for, the fee and the deadline written before acting.
- [ ] Real funders and agencies never charge to give money; any fee to receive, process or "release" funds is a stop (Big D's rule).
- [ ] Credentials entered only on the organization's own domain; nothing sent by email, text or chat.
- [ ] Confirmation captured (number, screenshot, receipt) and stored outside the repo in the encrypted documents folder; the ticket records only that it exists.
- [ ] Follow-up dates on the calendar with a reminder a week before.
- [ ] Tax consequences noted (set-aside, estimated payments) when money moves.
- [ ] Owner performed or explicitly delegated the action; Claude Code prepares, never submits.
