# hardware (devices, sensors, boards, physical builds)

- [ ] Bill of materials with versions and pin assignments recorded; power budget checked.
- [ ] Runtime evidence from the device itself (log line, photo, measurement), not from a simulator alone; simulation labeled simulation.
- [ ] Safe-off path: what happens on power loss, lost connection, stuck button; nothing moves or sounds without a way to stop it.
- [ ] Setup reproducible from a fresh image: image version, packages, config files committed or scripted.
- [ ] Physical isolation and cabling documented so someone else can rebuild it.
- [ ] Tests that need a human (timing, audio audition) have a recorded procedure and result.
