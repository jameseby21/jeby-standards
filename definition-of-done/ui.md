# ui

- [ ] Route registration, guards, navigation, titles and direct URL loading work.
- [ ] The intended role sees the entry point; another role does not.
- [ ] Loading, populated, empty, validation, unauthorized, unavailable, conflict, success and retry states are understandable.
- [ ] Labels and values verified in the rendered DOM, not by the presence of a component class.
- [ ] Controls enabled and disabled according to record state; double submission and stale state behave intentionally.
- [ ] Keyboard, labels, focus, contrast and a phone-width layout checked where the surface changed; real buttons and links, never clickable divs.
- [ ] No console error, build warning, invisible text or layout jump accepted without a recorded limitation.
- [ ] Screenshot or recorded walkthrough attached to the Report when the look changed.
- [ ] **Visible progress** (rule 10, James 2026-11-08): every action a person starts shows a bar with named steps or a count where they clicked, elapsed time after 2 s, then a readable success or failure sentence; no spinner alone; nothing scrolls or reloads the page.
